# Пульт охраны банка

Веб-приложение для мониторинга контроля доступа сотрудников банка. Подключается к удаленной базе данных с визитами и карточками пропуска сотрудников банка.

Пример запуска скрипта:
```
python manage.py runserver
```

Заходите на адрес `127.0.0.1:8000`, ваш сайт будет там.

### Как установить

#### 1. Клонируйте или скачайте проект

#### 2. Установите зависимости

Python 3.10.11 должен быть уже установлен. 
Затем используйте `pip` для установки зависимостей:
```
pip install -r requirements.txt
```
Рекомендуется использовать [модуль venv](https://docs.python.org/3/library/venv.html) для изоляции проекта.

##### 3. Создайте и заполните файл с ключами

Создайте `.env` файл в корне проекта. В нём должны быть:
```
DB_HOST=адрес_БД
DB_PORT=порт
DB_NAME=название_БД
DB_PASSWORD=пароль_к_БД
DB_USER=имя_пользователя
SECRET_KEY=секретный_ключ_сайта
DEBUG=False
```
